# STANLEY — Self Training Attention Non-Linear EntitY

**Proof of concept:** Models can speak BEFORE training if architecture enables resonance.

## 🎯 Try It

Select mode:
- **Weightless:** Pure architecture, zero pretrained weights, numpy-only
- **Hybrid:** Stanley (personality) possesses GPT-2 (knowledge), real-time weight modification

### Example Prompts
- "Tell me about yourself"
- "What is memory?"
- "How do you feel?"
- "What makes you different from other AI?"

## 🔬 Key Insights

✅ **Architecture > Parameters** — Intelligence is in structure, not scale  
✅ **Personality > Knowledge** — 64-dim personality field controls 768-dim GPT-2  
✅ **Ontogenesis > Phylogeny** — Becoming through experience beats inherited memory  
✅ **Mood = Weights** — Emotions are real-time weight modifications, not just tone  

## 🏗️ Architecture

### Weightless Mode
Pure pattern matching with zero pretrained weights. Proves that models can generate coherent language through architecture alone.

```
Input → SubwordField → ResonantRecall → Overthinking → Output
```

### Hybrid Mode
Stanley's personality hierarchically controls GPT-2's knowledge weights through mood-driven LoRA adapters.

```
Stanley (weightless) → MoodRouter → AdapterBank → GPT-2 (patched) → Output
```

## 📦 Installation

Run locally:

```bash
git clone https://github.com/ariannamethod/stanley.git
cd stanley
pip install -r requirements.txt

# Weightless mode
python stanley_run_dynamic.py --origin origin.txt

# Hybrid mode (requires torch + transformers)
pip install torch transformers
python stanley_run_hybrid.py --origin origin.txt

# Gradio demo
pip install gradio
python app.py
```
